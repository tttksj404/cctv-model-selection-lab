# 공개 가능한 세션 근거와 경계

## 실험 질문

사람 속성·식별·설명에 다른 모델을 무조건 합치지 않고, 각 역할에 맞는 후보를 같은 조건에서 비교한 뒤 승격 여부를 결정하는 것이 목표였다. 임베디드 속성 후보는 CLIP 계열, 서버 속성 후보는 SOLIDER, 재식별은 ReID branch, 저신뢰 충돌 설명은 Qwen3-VL로 분리했다.

## 확인된 사실

- 현재 비교는 45개 proxy person crop과 33개 그룹에서 같은 10개 속성 스키마를 사용한 제한된 벤치마크다.
- 동일 proxy 조건에서 CLIP ViT-L/14의 속성 정확도는 41.4%, Qwen3-VL-2B는 39.3%였으나, 이는 실제 CCTV identity accuracy가 아니다.
- 모델 출력·실행 조건은 manifest, notebook, 결과 JSON, source hash, gate report로 다시 읽도록 구성했다.
- 실제 identity·track-heldout 라벨과 독립 검수가 부족하므로 현재 판정은 `NOT_APPROVED`다.

## 공개하지 않는 것

이 저장소에는 CCTV 영상·프레임·개인 식별자·원본 라벨·모델 가중치·팀 서비스 코드·원격 서버 주소·계정 정보가 없다. 외부 데이터셋과 모델의 라이선스·사용 조건도 실제 재학습이나 배포 전에 별도로 확인해야 한다.

## 이 포트폴리오의 의미

이 프로젝트는 모델 성능을 과장하는 자료가 아니다. proxy 결과를 production 결과로 바꾸지 않고, 근거가 부족하면 보류하며, 실패 사유를 다음 실험 계약으로 환류하는 하네스·오케스트레이션·루프 엔지니어링의 공개 가능한 증거다.
