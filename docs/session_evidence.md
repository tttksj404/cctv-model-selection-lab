# 공개 가능한 증거와 경계

이 저장소는 모델 가중치나 CCTV 원본을 공개하는 저장소가 아닙니다. 후보 역할, 비교 조건, 측정 결과의 해석 범위, 그리고 보류 판단을 재현 가능한 문서·설정·테스트로 남깁니다.

공개 스냅샷에 포함하는 것은 다음과 같습니다.

- 후보별 역할과 상태
- 동일 프로토콜에서만 해석하는 집계 지표
- strict ReID의 Top-K 검색 허용과 자동 매칭 차단 결정
- manifest·heldout·provenance·사람 검토를 요구하는 promotion 조건

포함하지 않는 것은 실제 CCTV 영상, 프레임 경로, 개인 ID, 내부 서비스 코드, 비공개 notebook URL, 모델 가중치와 자격 증명입니다. 외부 benchmark 또는 proxy 지표도 실제 프로젝트 CCTV의 자동 매칭 성능으로 표현하지 않습니다.
